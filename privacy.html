Hermes Gmail ("the app") is operated by an individual developer for personal use. Back to home

Data we access

When you sign in with Google and approve the requested permissions, the app accesses Gmail data (such as messages and labels) within the scopes you granted.

How we use it

Data is used only to provide the features you request inside the app. It is not sold, not used for advertising, and not used to train generalized AI/ML models. It is not shared with third parties except as needed to run the features you invoke, and humans do not read your data unless you ask for it or it is required by law.

Storage and retention

Access tokens are stored securely on the operator's own system and used only to perform your requests. Email content is not retained beyond what is needed to complete a request.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your choices

Revoke access any time at myaccount.google.com/permissions. To request deletion of any stored tokens or data, open an issue at GitHub.
